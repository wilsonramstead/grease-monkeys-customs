## Build notes
- Single self-contained `index.html` — inline CSS + minimal JS, works from `file://` and with JS off.
- **Fonts:** Ruslan Display (display) + Sulphur Point (body), via Google Fonts.
- **Palette:** carbon-black + chrome + candy-red→ember flame accent (bold, flashy custom-shop aesthetic).
- `noindex` while it's a demo — remove the meta tag when the site goes live.
- Structured around all three service lines: Window Tinting, Auto Detailing, Customs & Restoration.
- All copy uses only facts from the Google listing/reviews — no invented emails, prices, license numbers or founding year.
- Gallery uses Unsplash stock, labeled as a placeholder to swap for the shop's real photos after sale.
